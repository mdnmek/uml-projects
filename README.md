# UML-projects
Здесь собраны лабораторные работы по моделированию программных систем с использованием нотации **UML 2.5**, выполненных в рамках прохождения курса "Формализация моделирования".

Все диаграммы созданы с подходом **"Diagrams as Code"** (с использованием PlantUML).

## Проекты в этом репозитории

| Проект | Описание | 
| :--- | :--- |
| [**Онлайн-школа**](./online-school-uml/) | Система автоматизации образовательной платформы |

## Используемые инструменты
* **PlantUML** — для генерации диаграмм из кода.
* **VS Code** — среда разработки.

## Для запуска необходимо:
1. Склонировать репозиторий.
2. Открыть любой `.puml` файл в VS Code с установленным расширением PlantUML.
3. Нажать `Alt + D` для предпросмотра.
